# 여주도자기 화인회

여주도자기 화인회 온라인 전시관입니다.

## 구조
- `index.html` — 메인 (현재 전시, 소개, 전시 기록, 회원 작가, 문의)
- `exhibitions/19th/` — 제19회 전시 페이지
- `assets/css`, `assets/js` — 스타일, 라이트박스·필터 스크립트
- `assets/img` — 사진 (전시별 하위 폴더 사용 권장)

## 새 전시 추가
`exhibitions/19th/`를 복사해 `exhibitions/20th/`처럼 만들고, 메인 `index.html`의 현재 전시와 전시 기록을 수정합니다.

## 문의 양식
`index.html`의 form `action`에 Formspree 주소를 넣으면 작동합니다.
